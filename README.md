# Netflix-_Data_Analysis
Netflix titles Data Cleaning,Analysis, and Visualization using python.
# Project Overview 
 - This project analyzes the Netflix titles dataset to understand the distribution and characteristics of movies and TV shows available on Netflix.
 - The project includes data cleaning,Exploratory data analysis(EDA),data visualization, and insight generation using python.
# Objectives
- Understand content ratings
- Analyze Top directors and actors
- Study content trends over the years
- Generate insights using visualizations.
# Tools & Technologies
python
pandas
Matplotlib,seaborn
Jupyter Notebook

# Project Workflow
1. Data Cleaning
 -Performed using Pandas:
-Handled missing values
-Cleaned categorical fields
-Prepared data for analysis

2. Exploratory Data Analysis
 Explored:
-Movies vs TV Shows
-Ratings and release years
-Directors and actors

3. Data Visualization
Created using Matplotlib and Seaborn:
-Bar charts
-Pie charts
-line charts
-Histograms

These helped reveal key trends in Netflix content.

# Key Insights

-Movies dominate the dataset compared to TV Shows
-Multiple rating categories are present
-Content has grown significantly over the years
-Clear patterns in popular content types, directors, and actors
